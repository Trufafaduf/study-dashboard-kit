How grading works

  1. Open an item and read the problem. Set a timer for the minutes shown.
  2. Write the steps you can on paper or your tablet, with the item's id at the top. Stop where you're stuck rather than guess: unwritten steps are marked N.
  3. Submit photos from the item's row in Submit work on the Obsidian dashboard, then tell Claude Code @@SUBMIT_CMD@@. Or copy the grading request here and paste it into Claude Code with the photo.
  4. Claude marks each rubric step yes or no, logs the attempt in your wiki, sets the status, and republishes this board.
  5. The item's rubric unlocks here once it is graded, so you can see which steps failed. Until then it isn't in this page at all.

A phone photo of one page costs Claude about 1,500 tokens, so a three-page answer is roughly 5,000. One photo per page, flat and in focus, reads best.
